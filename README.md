# Healora Clinic – Clinic Appointment Management System

## 1. Project Title and Description

**Project Title:** Healora Clinic – Clinic Appointment Management System

Healora Clinic is a web-based Clinic Appointment Management System developed to make the appointment process easier for patients and clinic administrators. The system allows patients to register, log in, view doctors and clinic services, and manage their appointments. Administrators can manage clinic operations through the admin dashboard.

## 2. Main Features

The main features of Healora Clinic include:

- Patient registration and login
- Patient dashboard
- Online appointment booking
- View doctor information
- View doctor schedules
- View clinic services
- Manage patient appointments
- Admin dashboard
- Manage doctors and clinic schedules
- View appointment history and reports

## 3. Instructions for Testing the Login

Patient Login:
1. Open the Healora Clinic website.
2. Click the Sign Up button to create a new patient account.
3. Enter the required information.
4. After registration, log in using the registered email and password.
5. The patient dashboard will be displayed after successful login.

**Admin Login:**
1. Open the login page.
2. Enter the administrator login credentials configured in the system.
3. Click the Login button.
4. The admin dashboard will be displayed after successful login.

## 4. Frameworks and Libraries Used

The following technologies and libraries are used to develop the system:

- **HTML5** – Structures the website content.
- **CSS3** – Styles the website layout and appearance.
- **JavaScript** – Handles system functions and user interactions.
- **Bootstrap 5** – Provides responsive layouts and interface components.
- **Bootstrap Icons** – Provides icons for the website.
- **Local Storage** – Stores selected system data in the browser.
